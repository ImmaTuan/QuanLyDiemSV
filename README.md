1.Cài đặt project
git clone https://github.com/ImmaTuan/QuanLyDiemSV.git
cd quanlydiemsv
Cài đặt thư viện : composer install
Cấu hình .env : cp .env.example .env
Tạo key : php artisan key:generate

2.Cài đặt db
Sử dụng xampp cài đặt db được lưu trong file database 

3. Chạy ứng dụng
php artisan serve
